#### The Human Reference Genome
- Usually, we chop up DNA and then feed it into deep learning models. We thought we needed labels for every piece of DNA, but what about the DNA of variation between individuals. The question is What is this reference genomic sequence and where did it come from? Actually better to say who. It isn't known exactly who makes the referenc genome. They asked anoymous volunteers about 13 in Buffalo and collected high quality genomes. One person accounts for 60-70% of the total. All these samples contain the alleles for Type O blood. This is strange so what if you wanted to predict genomic effects on other blood types. They would update and patch up the reference genome every few years, but mostly to fill gaps. There are 13 million bases that make up the reference genome. 
- Why a reference genome? Having only one person's genome sequenced isn't right. *de novo* assembly is hard, read mapping is easy. de novo is trying to assemble puzzle without a picture. Read mapping is easier as you can match to a picture. The second reason is that it gives a frame of reference to compare genomes. When you have two genomes, you can align them to the reference. This simplifies the whole process of making comparisions. Third, allows us to refer to specific location in the genome. Allows us to make relative position claims. Enhancer EH38E3207265 is 2000 bases from TP53 gene. Easy to visualize. The reference genome makes processes more feasible, but there is no actual person where this is accurate or correct!

This is reference bias, only will have parts or reads that map back to the reference genome.

#### Simple Idea: A "Consensus" Human Genome
- Take the most common and major alleles. This is only simple when you consider small alleles. The reference will only have the common stretches and pieces. This solves an obvious problem, the current reference genome has a lot of rare alleles than the consensus, it'll turn the reference into a common genome. The way this would work, when you sequence more genomes, update the data based on the allele frequencies. But the consensus genome is western dominated. The advantages is that this is pretty simple when you consider just common, it solves some of the problems of the reference. But this is a partial band-aid solution, it doesn't incorporate diversity or variation. 
- How about we built consensus genomes per-population. But this is still a band air as defining the populations is challenge, wouldn't you have to make so many to represent so much diversity. This is better than the reference, but it is a band aid. 
#### Human Pangenomes
- A human pangenome is trying to capture variation, can we build a reference genome that captures all the human variation. 
- This example figure shows that each individual has genes that are and aren't captured in the reference. 
- Start first with a simple idea: **Presence Absence Variation Pangenome**. Just mark if genes are core and accessory genome. The main this is that this is more a catalogue and is reference free. Keep a count so this is simple and fast. And it'll account for all vatiation in key functional units. Something outside of scope, it is very powerful for pan transcriptomics for several species and build a whole universal understanding of genomics.
    - But it requires it to depend on functional units, need a prior knowledge of where to count and what counts. Because of that we don't use this instead of reference genome, but it's usually used for cross species in metagenomics where you take several species' genomes and compare and contrast their genes. This would be great if we just want to see what genes are expressed and not and different. 
- The second is a Representative Sequence Pangenome. This extends past the reference where you take all the unaligned reads and see where they overlap and build contigs. This gives us a set of contigs that are not seen in the reference. What you end up with is a reference genome but with alternative genes. So in the human genome. There's a noise threshold and anything past that is past, will add to the contig. This is for longer bits of DNA that don't originally align. 
    - Advantage: captures common variation and removes large fraction of the reference bias. This is simple, linear, fast, and keeps the reference. 
    - Downside: does require reference. The other issue is that these contigs are often ignored, default analysis will align to the reference and bioinformatics usually discard these contigs and are often ignored, because it is extra analysis work to keep in mind. This is ignored because it doesn't contextualize the extra contigs that don't feel important and we don't know what they do. The human reference genome (hg38) is actually made this way with hundred of thousands of contigs. People still use the previous reference genome hg19.

#### *De Novo* Human Pangenome Graph
- How are de Bruin graphs constructurd for a single genome. 
- Break down the 3-mers into 2-mers. Check where the end of one match the start of another. Glue these edges together, never delete edges. Eventually you get a graph. Where nodes are k-mers and edges are connections. The assembled sequence is an Eulerian path through the de Bruijn graph. How do we know where it starts and ends? Find where in the graph which has one less degree for the start and for the end. This sequence contains every kmer/sequence exactly once.
